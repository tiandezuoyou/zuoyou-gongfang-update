## 一、安装与启动

### 1.1 图标启动（推荐）

1. **第一次**：双击主目录下的 **`创建桌面图标.bat`**，桌面出现「左右工坊」图标
2. 以后双击桌面那个 **「左右工坊」图标** 启动（也可直接双击 `左右工坊.exe`）
3. 自动弹出**原生软件窗口**（像普通 Windows 软件一样，没有黑框、不依赖浏览器），启动时有一小段加载
4. 关掉窗口即退出

> **exe 是单文件、自包含的**：后端与前端界面都打在里面，只复制这一个 exe 也能跑（小说 / 视频 / 图片 / 音频 / 模型配置全部可用）。
> **但「小说工坊一 · 创作中枢」需要同目录的 `inkos\` 引擎文件夹**（约 2.7GB）。整个文件夹一起拷贝才能用创作中枢；
> 只拷 exe 时中枢页会提示「未随包提供引擎」，其余功能不受影响。

### 1.2 原生窗口（WebView2）

首次打开若弹出的是**浏览器窗口**而不是原生窗口，说明本机缺 WebView2 运行时——双击 **`安装WebView2.bat`** 装一下，以后就都是原生窗口了（不装也能用，只是走浏览器）。

### 1.3 数据存在哪？

exe 是便携的，所以你的小说工程、配置等可写数据统一落在当前用户目录：

```
C:\Users\你的用户名\AppData\Roaming\左右小说制作器\
├── 作品\              ← 你创作的小说（每本一个文件夹）
├── data\              ← 配置(config.json) + API Key 保险库
│   └── logs\左右工坊.log  ← 运行日志（v4.2.8 起每次启动都留一行）
├── InkOS用户数据\      ← 创作中枢（工坊一）的引擎数据与模型配置
├── img_cache\  video_cache\  audio_cache\  song_cache\  drama_cache\   ← 各类产出的缓存
├── WebView2\          ← 原生窗口的浏览器配置（v4.2.7 起固定放这儿）
└── launcher_debug.log ← 启动日志（排查启动问题时看这个）
```

> **v4.2.7 起：不再往系统 Temp 里丢垃圾了。**
> 旧版本有个隐藏毛病 —— 软件每次启动会把自己解压到 `C:\...\Temp\_MEIxxxxxx`
> （约 200MB），**正常关窗**时会被清掉，但如果软件是被**强制结束 / 系统关机 / 崩溃**
> 带走的，这份解压目录就留在 Temp 里了，一次约 200MB。用得久了，Temp 里能堆到
> 十几个 GB，C 盘莫名其妙变小。
> 现在：① 启动时会**自动把历史遗留清掉**（只清带本软件特征、且超过 30 分钟的目录，
> 绝不碰别的程序）；② WebView2 的配置目录固定放在上面的 `WebView2\` 里，
> 不再每次在 Temp 建一个 `tmpXXXX`。你什么都不用做，装新版第一次启动会自动回收。
>
> **v4.2.8 又补了两处（都是实测出来的坑）**：
> ③ 旧版清理只认「目录名是 `_MEI` + 纯数字」的老格式，于是名字里带字母的那些自家残留
> （形如 `_MEI000020a42`）**永远清不掉**。现在改成按目录**内容**认归属，并在启动时往
> 自己的解压目录写一枚归属标记，往后判断不再靠猜。
> ④ 退出时清理经常失败 —— 元凶是 WebView2 的子进程还活着、手里握着解压目录里的 DLL。
> 现在退出前会先等它退干净再删。**就算还删不掉也不影响使用**：下次启动照样回收。
>
> **顺带修掉一个「排查盲区」**：以前 `data\logs\左右工坊.log` 只在软件**崩了**的时候
> 才有内容，所以日志常年是空的 —— 出问题时既看不到「软件到底有没有起来」，也看不到
> 版本和端口。v4.2.8 起每次启动都会写一行，比如
> `启动 v5.8.52 | 端口 41777 | 数据目录 D:\... | 作品目录 D:\...`；
> 万一日志文件写不进去，也会在控制台明说，不再静默吞掉。

**无论 exe 放在哪都不会丢数据**，卸载软件（删 exe）也不影响这些内容。
侧栏左下角的 **◎目录** 按钮可以直接打开总目录，**一键自检**在「模型配置 · 🛠 高级设置 → 数据与备份」里。

### 1.4 界面总览

- **左侧导航**：6 个可折叠分组，点分组标题展开/收起。当前页高亮。
- **沉浸模式**：除「模块大厅」外的所有页面会自动进入沉浸模式——左侧栏收成半透明，品牌变成左上角一个小芯片，底部三个按钮（主题/目录/更新）沉到左下角变成胶囊按钮，让出整屏给内容。
- **← 返回键**：右上角圆形箭头，回到「模块大厅」。
- **侧栏左下三个按钮**：`☾主题`（浅色/深色切换）、`◎目录`（打开产出总目录）、`↻更新`（检查新版本）。
- **当前作品**显示在按钮上方，写小说时注意别选错作品。

## 二、开跑前必须做的一件事：配置模型

**所有生成能力都要先配模型**，否则点「生成」只会提示你去配置。这一节是全书最重要的一节。

### 2.1 五类模型域（先建立概念）

软件把模型按用途分成 **5 类**，**互不混用**（各自的 Key 分开存）：

| 模型域 | 服务于 | 说明 |
|---|---|---|
| **小说模型** | 小说工坊一 / 小说工坊二 | 两个工坊可**分别**指定，互不影响 |
| **视频模型** | 视频工坊 | 文生视频 / 图生视频 / 短剧 / 科普 |
| **图片模型** | 图片工坊 | 文生图 / 图生图 / 立绘 / 场景；另可单独指定**封面模型** |
| **音频模型** | 音频工坊 | TTS 语音合成、有声书 |
| **歌曲模型** | 歌曲生成 | 本地 ACE-Step / Suno 兼容网关 |

> **一个功能可能要配多个域**。例如「短剧模式」同时用到 ①小说/云端模型（分析剧本）②图片模型（人物关键帧）③音频模型（角色配音）。

### 2.2 模型配置页 —— 7 个并列入口逐个讲

入口：模块大厅「模型配置」卡片，或左侧导航里单列的「⚙ 模型配置」分组（它不再和其他页面混在一起）。

> **v5.6.0 改了结构：4 个分组 → 7 个并列入口，每个入口只有一个主题。**
> v5.5.0 把「同一个 Key 要在四处各填一遍」的问题解决了，但中间那个「模型选择」里
> 还塞着 6 个内容域（靠顶部锚点按钮来回滚），点进去仍然是「一个页面看六个域的东西」。
> 现在拆开：**填 Key 的只有一处，其余 6 个入口各自只装自己那个域的内容**。
> 分层依据：API Key 是「账号级」的（一家厂商一个 Key，横跨多个域也只填一次），
> 模型名与生成参数是「域级」的（同一厂商在各域的名字、端点、尺寸时长都不同）。

| # | 入口 | 里面只有这些东西 |
|---|---|---|
| ① | **🏢 厂商与凭据** | **全软件唯一填 API Key 的地方**。**一家厂商一张卡，一张卡只填一个 Key** —— 同一家厂商横跨对话 / 视频 / 图片 / 音频时也只填一次。可按厂商名或域名搜索、按内容域筛选、勾「只看未配置」。顶部总览芯片一眼看出哪个域还没配；「备份 / 恢复 API 配置」「导出脱敏配置」也在这里 |
| ② | **📖 小说模型** | 三个智能体（规划 / 写作 / 修订）各一个**下拉**，挑已配好的模型；下面是对应厂商的模型名卡与两个检测按钮 |
| ③ | **🎬 视频模型** | 视频厂商的模型名 + 体检 + **视频生成参数**（时长 / 分辨率 / 画面比例 / 模式 / 种子） |
| ④ | **🖼️ 图片模型** | 图片厂商的模型名 + 体检 + **图片生成参数**（尺寸 / 张数 / 种子）+「小说封面默认出图」 |
| ⑤ | **🎙️ 音频模型** | 上半段是 **TTS 语音**（音频工坊 / 有声书 / 短剧配音），下半段是 **🎵 歌曲引擎**（本地 ACE-Step / Suno 兼容网关）—— 两套对接，**Key 各自独立** |
| ⑥ | **💻 本机与本地模型** | 本机环境 + 本地模型（Ollama）两块 |
| ⑦ | **🛠 高级设置** | 智能体路由（采样质检）+ 下载加速 + 模型竞速 + 数据与备份 |

这 7 个入口是**并列**的（顶部一行标签，点一下直接切过去），进去只看到自己那一段内容。

**② 📖 小说模型** 里有什么：

| 区块 | 作用与用法 |
|---|---|
| 🧭 **三个智能体下拉** | 规划 / 写作 / 修订各挑一个模型（对应「高级设置 → 智能体路由」里的角色）。**只列「已经配好」的模型**，不会塞一堆用不了的名字 |
| 🚀 **写作模型（小说工坊一）** | 给 InkOS 创作中枢选模型 → 点「用这个模型写作」即生效 |
| 🔎 **两个检测按钮** | `⚡ 检测能不能出字`、`🧰 检测工具调用（写短篇 / 整书必查）`——**写整书这两个都要过**，弱模型工具调用不合格会导致中途「确认动作失败」 |

**③ 🎬 视频模型**：挑视频厂商的模型名（含自定义端点，可并存多个）、`🩺 体检本类模型`（可勾选**含实拍验证**），再加一组**视频生成参数**（时长 / 分辨率 / 画面比例 / 模式 / 种子；留空 = 用默认，生成页当次请求优先级更高）。

**④ 🖼️ 图片模型**：挑图片厂商的模型名（**Pollinations 完全免费、无需 Key**）、体检（含实拍：合成两个字）、**图片生成参数**（尺寸 / 张数 / 种子），以及 📕 **小说封面默认出图**——指定封面专用模型后点「保存为封面默认」。封面用的就是**图片**那一域的厂商与模型。

**⑤ 🎙️ 音频模型** 由上下两段组成，**是两套完全独立的对接**：

| 段 | 作用与用法 |
|---|---|
| 🎙️ **TTS 语音** | 挑语音厂商与模型名，供「音频工坊」（文本转语音、整本有声书）与「短剧模式」的角色配音使用。含体检（拉厂商真实模型清单） |
| 🎵 **歌曲引擎** | 配歌曲生成的后端（本地 ACE-Step / Suno 兼容网关自定义端点），供「音频工坊 → 歌曲生成」使用。**与上面的语音 Key 各自独立**，别指望填一个两边都能用 |

**⑥ 💻 本机与本地模型** 的两个分节：

| 分节 | 作用与用法 |
|---|---|
| 🖥️ **本机环境** | 看本机配置；Ollama 引擎的 **安装 Ollama / 启动服务 / 停止服务 / 刷新**；`一键装全套`、`按本机自动分配角色`、`在文件夹内自动查找` |
| 📦 **本地模型** | 已安装 / 模型库浏览 / 自定义 GGUF 加速下载。按本机显存内存推荐可流畅运行的量化版本 |

> **关于 Ollama（本地模型引擎）**：
> Ollama 是**可选**的 —— 只用云端模型（DeepSeek / 智谱 / 硅基流动等）的话，**完全不装也能正常写小说**，
> 软件也不会来烦你。要用本地模型时，有三条路：
> ① 启动时若检测到没装，会问你要不要自动装（点「是」即可）；
> ② 在这一页点「**一键安装 Ollama**」按钮（用随包安装器，约 1.4GB，装完需重启软件）；
> ③ 手动双击发布包里的 `安装Ollama.bat`。
> 装了之后别忘了回到「本机环境」点 `启动服务`，本地模型才连得上。

**⑦ 🛠 高级设置** 的四个分节：

| 分节 | 作用与用法 |
|---|---|
| 🧭 **智能体路由** | 三个智能体各用哪个模型 + 采样与质检参数（详见 2.7） |
| 🚀 **下载加速** | 下载源测速、加速参数、下载任务（可选 modelscope / hf-mirror 镜像） |
| 🏁 **模型竞速** | 「参赛选手」同一提示词多模型对比，挑出最合适的那个 |
| 💾 **数据与备份** | 数据备份与恢复、一键自检、运行缓存清理 |

### 2.3 一张厂商卡片怎么填

**凭据（Key / 地址）在「① 🏢 厂商与凭据」里填，模型名在各域入口（② ~ ⑤）里填** —— 这是最需要记住的一条。

在「① 🏢 厂商与凭据」：

1. **找厂商**：可以按**厂商名或域名**搜索（如 `hcnsec`、`dashscope`），也可以按**内容域**筛选、勾「只看未配置」——内置 34 家预设（覆盖 DeepSeek、硅基流动、通义千问、Kimi、智谱、火山方舟、MiniMax、OpenRouter、OpenAI、Claude、Gemini、Pollinations 等）。
   > 找不到你要的？到对应的域入口（② 小说 / ③ 视频 / ④ 图片 / ⑤ 音频）点 `＋ 新建自定义端点`，会**自动跳到厂商页并筛出那个域**，给你一张待填的卡，接任意 **OpenAI 兼容**接口（vLLM / LM Studio / One-API / 中转站都行）。填错了点卡上的「删除端点」即可。
2. 填 **API Key** 和 **Base URL**（预设厂商会自动带好地址，通常只需填 Key）。
3. 点「**保存**」。可以点「测试」立刻验证 Key 与地址是否可用。

再到对应域的入口（📖 小说 / 🎬 视频 / 🖼️ 图片 / 🎙️ 音频）：

### 2.4 模型名称怎么填（重要）

- **一行一个模型名**，不要在一个框里塞多行或用逗号堆一串。
- 名字必须是厂商**真实存在**的模型 ID（如 `deepseek-chat`、`qwen-plus`）。填错会在生成时报 `model_not_found`。
- 拿不准就点 `↻ 拉取模型`，让软件把厂商账号下**当前真实**的模型名拉出来，**点一下即填入**。
- 同一厂商要配**两套 Key / 两个端点**？到「① 厂商与凭据」点 **`📋复制框`** 克隆一份再改，**别在一个框里堆**。

#### 2.4.1 `↻ 拉取模型` 的 ✓ / ✕ 是什么

点 `↻ 拉取模型` 后，软件不只是把厂商给的名单列出来，还会**对每个名字真发一次请求验证**，结果直接标在名字后面：

| 标记 | 含义 | 怎么办 |
|---|---|---|
| **✓**（绿色） | 实测可用 | 放心点它 |
| **✕**（橙色） | 实测不可用 | **点它会被拦下**并说明原因，请换一个带 ✓ 的 |
| 无标记 | 没能验证（通常是账号级问题，见下） | 看弹窗提示 |

> **为什么必须验证**：厂商的模型接口给的是一份「**名义清单**」—— 里面可能混着**已经下架**、或**没给你的账号开渠道**的名字。名字在列表里 ≠ 真能调用。所以软件会实测一遍，避免你选中之后保存、测试才发现跑不起来。

#### 2.4.2 测试报错怎么读（这几种不是一回事）

| 提示 | 真正的原因 | 该做什么 |
|---|---|---|
| **账号的余额/额度不足** | **不是 Key 的问题**，重填 Key 没用 | 去厂商控制台**充值**或领免费额度 |
| 模型名不被该厂商识别 | 这个名字厂商不认（已下线 / 压根没有） | 点 `↻ 拉取模型`，选带 **✓** 的 |
| 该模型名当前**没有可用渠道** | 名字合法，但厂商没给你的账号开这个渠道 | 换一个带 **✓** 的模型 |
| 该模型已被厂商**下线**（end of life） | 模型停售了 | 换一个带 **✓** 的模型 |
| API Key 无效或无权限 | **这个才是 Key 真的错了** | 重新填 Key |

弹窗里都会附上「原始错误」，可以**直接复制给厂商客服**。

#### 2.4.3 点了没反应 / 提示一闪而过？

软件里**任何操作失败都会在右下角弹出一条红色提示**并写明原因。如果你遇到这几种情况：

| 现象 | 说明 | 怎么办 |
|---|---|---|
| 点了按钮，界面毫无变化 | 旧版本有部分操作失败时是「静默」的 | 升级到 **v4.2.4 及以后**：失败一定弹出原因 |
| 提示一闪而过、来不及看清 | 旧版本提示固定只停 2.6 秒 | v4.2.4 起：**报错提示默认停 6 秒**，模型相关长提示停 11~13 秒 |
| 右下角堆了一串提示 | 多个请求同时失败 | 最多同时显示 **5 条**，超出会自动顶掉最旧的；同一原因 3 秒内不重复弹 |
| 想立刻关掉某条提示 | — | **点一下那条提示即可立刻关闭** |

> **v4.2.4 修了什么**：以前提示函数的「停留时长」参数被程序**静默忽略** —— 调用处明明写了停 11~13 秒，实际一律 2.6 秒就消失，模型那种长报错根本来不及读，看起来就像「点了没反应」。现在时长真正生效，并新增了一层**全局兜底**：即使某个操作没单独写错误处理，失败也会把原因弹出来。同时给大模型配置页的「保存设置 / 保存路由 / 保存加速参数 / 重新检测硬件 / 自动分配角色」以及书架、导出、清除配置等按钮补上了「进行中…」状态与失败提示。

**每本书是一个独立文件夹**：真相文件、大纲、正文、审计全部落盘，随时可用记事本打开。

### 5.2 设定工坊（五步总览 · 每一步的产出直接摊在页面上）

入口：「✦ 设定工坊」。**五步纵向排列**，每一步都是一张卡片，卡片里**直接把这一步到底生成了什么摊开给你看**——分节标题、章号区间、章节名与核心事件、每份真相文件的字数与摘要、正文字数与缺章清单，不用再逐个文件点开翻。

| 步骤 | 页面上直接显示的内容 | 可以点的按钮 |
|---|---|---|
| **① 世界设定** | 状态徽标 + 字数 / 分节数 + **每个分节的标题与首句摘要** | `生成世界设定`、`查看 / 编辑` |
| **② 真相文件** | 状态徽标 + 已填写份数 + **7 份文件逐行列出行数与摘要** | 点某一行就地展开编辑 |
| **③ 总体规划** | 状态徽标 + 阶段数 + 已覆盖章数 + **每段的章号区间与阶段主题** | `生成总体规划`、`查看 / 编辑` |
| **④ 章节蓝图** | 状态徽标 + 已规划章数 + **每章的章名 / 核心事件 / 钩子** | `分段生成章节蓝图` + 「每段章数」、`查看 / 编辑` |
| **⑤ 正文** | 状态徽标 + 已完成章数 / 平均字数 + **缺章清单** | `去章节流水线写正文 →`、`查看正文` |

**状态徽标分三档**，一眼判断这一步靠不靠谱：

| 颜色 | 文案 | 含义 |
|---|---|---|
| 🟢 绿 | `已完成` | 有内容且过了质检 |
| 🟡 黄 | `未开始` / `内容偏少` / `还没写全` | 有内容但不够（例如蓝图只写了 5/20 章） |
| 🔴 红 | `质检未通过` | 内容里有废文本或 AI 思考过程泄漏，**没有写进文件** |

卡片下方还有一条「**需要注意的地方**」提示，指出会导致后面跑偏的问题（例如「章节蓝图只写了 5/20 章，缺的部分不会自动补，直接生成正文会跑偏」）。**它不挡你继续操作，但会直接决定后面正文的质量**，建议先补上再往下走。

其他按钮：

- **🚀 一键走完并生成全文**：五步全自动跑完（想省事用这个，想精细控制就逐步来）
- **↻ 刷新**：重新读一遍磁盘上的产出，刷新五张卡的显示（你自己在别处改过文件后点它）
- **题材雷达**：分析当前题材趋势，给选材建议
- **总章数 / 每章目标字数**：在这里改，会直接同步给后面的规划与正文（目标字数 1500~2000）
- **中止生成 / 取消**

**页面底部的编辑抽屉**：点任意一步的「查看 / 编辑」，页面底部会展开抽屉直接改这个文件，不用跳去别的页面。点 `收起` 折叠。

> 💡 **若「总体规划 / 章节蓝图」只写到一半就停了**——那是模型单次输出长度被截断。把「每段章数」调小，让软件自动分段生成即可绕开。

> **v4.2.6 改了什么**：旧版是「左边四个步骤按钮 + 右边一个编辑器」，点了按钮只看到状态变了，**根本不知道到底生成了什么**，得挨个文件点开翻。现在改成**五步纵向 + 产出内嵌**：每一步的产出**摘要级**直接列在卡片里，内容有没有生对一眼就能看出来。

> **⚠️ 质检拦截（v4.2.6 新增，很关键）**：所有生成内容在写盘前都会过一遍质检，识别两类问题——
> ① **废文本**：模型自我对话 / 道歉 / 摆烂 / 逐字重复 / 乱码 / 空标题 / 句子被截断；
> ② **AI 思考过程泄漏**：正文里混进了模型自己的推理和英文内心独白（例如 `Let me restart...`、`I will not output the reasoning process, just the plot content`）。
>
> 命中后的表现：**内容不会写进文件**（避免脏地基污染后面所有步骤）→ 该步状态变**红**并写明命中原因 → 重新生成一次即可（多半是那一次模型抽风）。
>
> 为什么必须做这一步：实测出现过「章节蓝图里混了 7000 多字符英文内心独白，而旧版把它当成合格内容」。规划类产出是后面每一步的地基，**地基脏了，正文一定跑偏**。

入口：「⊕ 大纲与图谱」。两个子页：

| 子页 | 内容 |

>   关系名会自动避开节点名字，不再叠字。

### 5.4 章节流水线（核心生产页）

入口：「⛭ 章节流水线」。**十个阶段自动接力**：

```
规划师 → 建筑师 → 写手 → 确定性闸口 → 质量守卫 → 审计员 → 修订员 → 文风师 → 观察员 → 归档
```

- **确定性闸口**是纯算法检查（不调用大模型、毫秒级），检查错别字、字数、对白占比、禁用词等
- **质量守卫**（v4.2.9 新增，同样不调模型、毫秒级）查「读起来像不像人写的」：AI 味（重复句 / 套话腔 / 讲解腔 / 形容词堆砌）、注水（复述、原地打转、设定倾倒）、视角越界、角色出戏（对照角色卡）、节奏（有没有钩子 / 反转 / 高潮标记）
- 通过后由**审计员**做 33 维连续性审计，不达标交给**修订员**定点修（最多 2 轮）
- 最后**文风师**去 AI 味改写，**观察员**抽取事实写回真相文件，**归档**

> **质量守卫不过 = 直接打回，不看模型给的分。** 审计员是模型打分，可能给出一个不错的分数；质量守卫是硬规则，只要命中就打断，不会因为「综合分够高」被平均掉。

操作按钮：

| 按钮 | 作用 |
|---|---|
| **启动流水线** | 开始逐章生成 |
| **⏸ 暂停** / **中止** | 中途暂停或终止 |
| **继续生成** | 接着往下写 |
| **重新生成本章** | 对当前章不满意，重来一遍 |
| **确认放行** | 人工确认某章可以过 |
| **跳过后续** | 跳过某些阶段直接归档 |
| **终止** | 结束本次运行 |
| **↻ 刷新** | 刷新任务状态 |

> ⚠️ **重要规则：生成第 N 章前，必须先在编辑器里把第 N-1 章点「🔒 锁定本章」。**
> 这是防止 AI 写到一半前面又变了、导致连续性崩掉。软件会在你没锁定时直接拦下并提示。

> **v4.2.6 补了一条：哪一步失败会明确说出来，不再静默跳过。** 以前某个阶段出错（例如模型连不上）时，界面只是停住、不告诉你原因，看起来像「没反应」。现在每一次失败都会在下方进度区列成清单，写明**是哪一步、为什么失败**（附带模型原话），跑完也不会自动消失——你可以照着它去修模型配置或重试。

**每章字数硬性约束**：**1500 ~ 2000 字**（目标 1750）。超出区间会被自动夹回；不足会被要求补写。
> **v4.2.11 把这条线从 2000~2500 调成了 1500~2000。** 原因是「每章只有 500 字」的反馈：
> 不少模型（尤其是会先输出一段「思考过程」的）会把单次请求的输出预算吃掉一大半，
> 正文还没写完就被硬截断，而程序以前**完全没看厂商回的结束原因**，截断了也当写完了。
> 现在撞到上限会明确提示你去「模型配置 · 🛠 高级设置 → 智能体路由」的采样参数把 **max_tokens 调大（建议 ≥ 8192）**，
> 或者换一个不输出思考过程的模型。

> **v4.2.12 补充：换了模型还是写不够，先看它是不是「推理模型」。**

### 5.9 角色卡（多人物能力）

入口：「👥 角色卡」。**一人一卡，落在 `作品\<书>\设定\角色卡.json`**，同时生成一份人可读的 `角色卡.md`。

为什么需要它：角色一多，最容易出的问题不是「记不住名字」，而是**每个人说话一个味**——对白只剩「他说」「她说」，
读起来像同一个人在自问自答。角色卡把每个角色的**语音指纹**显式写下来，然后**写手和质检共用同一份**：
写这一章时只把「本章出场角色」的卡交给写手，写完再用同一份卡核对口吻。一张卡只维护一次，两边都受益。

| 字段 | 作用 |
|---|---|
| 姓名 / 身份 | 基本信息 |
| 性格锚点 | 行为准则——越具体越有用（「信证据不信直觉」远好过「冷静」） |
| 目标 / 弱点 / 秘密 | 驱动冲突的三件套 |
| 别名 / 口头禅 | 称呼与语言标记 |
| **语言习惯** | 句子长短、书面还是口语（例：短句、少修饰） |
| **语气** | 冷 / 急 / 慢条斯理 |
| **高频用词** | 这个角色爱用的词（顿号分隔，例：船票、编号） |
| **回避措辞** | 这个角色**绝不会说**的话（例：我觉得、或许吧） |

| 按钮 | 作用 |
|---|---|
| `⟳ 从图谱 + 设定补齐` | 从「关系图谱」+「世界设定」抽出角色骨架；**只填空白字段，绝不覆盖你手改过的内容** |
| `重建` | 丢掉手改内容按图谱+设定重抽一遍（会二次确认） |
| `＋ 新角色` / `删除` | 手工增删 |
| `查看 Markdown` | 看 `角色卡.md` 全文，可直接复制进素材中枢或做图文卡 |
| `保存` | 落盘到 `设定\角色卡.json` + `角色卡.md` |

> **「回避措辞」是最有用的一栏。** 它的判定是硬性的：只要出现一次就判该角色「出戏」，
> 不会被其它项的平均分盖过去——因为它表达的是一条明确声明（「这个角色不会这么说话」），不是一条软性偏好。

> 角色卡也是「本章视角（POV）」的实现基础：蓝图里每章写了 `POV：陆停`，写手就按陆停的视角写，
> 质检再按角色名单核对有没有写到别人的内心（限知视角下写别人的心理活动就是越界）。

**输入剧本 → AI 拆解人物/场景/对白 → 可改 → 生成人物一致、音色统一、带字幕的短剧视频**。

三步走：

| 步骤 | 按钮 | 说明 |
|---|---|---|
| ① | **🎭 分析剧本** | 粘入剧本 → AI 拆解（也可 `📖 从当前作品章节转剧本`） |
| ② | **✍️ 生成脚本与分镜** | 产出可编辑的结构（② 编辑结构（可改））；`💾 保存项目` / `📄 导出脚本` |
| ③ | **🎬 生成短剧视频** | 逐镜出片 + 合成；**⏹ 取消** 中止 |

短剧同时用到 **① 小说/云端模型（分析剧本）② 图片模型（人物关键帧）③ 音频模型（角色配音）**，这三类都要在模型配置里配好。

#### 🎓 知识科普
**选题与生成 → 脚本与分镜 → 分镜（逐镜出片）**，产出「我的科普项目」，适合做知识类短视频。

#### 🗂 我的视频
所有已生成的视频在这里统一查看、管理、下载。

## 七、图片工坊

### 7.1 图片模型 / 封面模型

- **图片模型**（「◐ 图片模型」）：图片大模型对接。**Pollinations 完全免费、无需 Key**；也支持硅基流动 FLUX、智谱 CogView、通义万相、即梦 Seedream、本地 ComfyUI、hcnsec 等。
- **封面模型**（「📖 封面模型」）：单独指定**小说封面**专用的出图模型 → `保存为封面默认` → `🎨 去「图片生成」出封面`。

### 7.2 图片生成

入口：「🎨 图片生成」。用云端图片大模型 / 免费 Pollinations 把文字、角色设定变成插画、立绘、封面、海报：**小说封面、角色立绘、场景、卡通、动漫、写真**等都能做。

| 区块 | 内容 |
|---|---|
| **生成类型** | 选分类（支持 `＋ 自定义分类`、`⭳ 导出分类`、`⭱ 导入分类`） |
| **🖌️ 手绘风格库** | 330 种编号画风 + 36 主题色，选中后自动拼进提示词（见 7.2.1） |
| **人物一致性设定** | `＋ 添加角色`、`📷 定妆照`、`🧊 三维图`、`不指定` —— **锁定人物一致性** |
| **生成** | 提示词（可 `从当前作品简介填充`、`✨ AI 润色提示词`）+ `🎨 生成图片` |
| **我的图片** | 历史产出管理 |

### 7.2.1 手绘风格库（330 种编号画风）

入口：「🎨 图片生成 → 🖌️ 手绘风格库」。内置开源库 **handraw-style** 的全部 330 种手绘画风，每种一个编号、一张参考图，不用再憋「治愈一点、文艺一点」这类模糊词——**看图选编号**即可。

| 操作 | 说明 |
|---|---|
| `🖼️ 打开风格画廊` | 弹出画廊：顶部搜索（编号 / 风格名 / 作者）+ 分组标签（FA 国际社论幽默、FB 经典绘本叙事、FC 现代平面、FD 日本当代、FE 新国风、FF 3D 黏土毛毡、FG 动漫赛璐璐、FH 先锋实验），点卡片即选中 |
| 选中后 | 卡片上方显示已选风格：新编号 `#FB-006` + 传统编号 `041`、风格名、参考作者 |
| `🎨 换主题色` | 可选叠加 36 种经典单色。弹出**画廊式选色窗**：顶部搜索（编号 / 名称 / 意境词，如 `C-10`、`鼠尾草`、`治愈`）+ 分组标签（经典蓝系 6、清新绿系 6、古典红绿 6、浪漫粉紫 6、暖阳大地 6、中性色系 6），每张卡片有色卡大图、编号名称和一句意境描述（如 C-01 克莱因蓝「纯粹之蓝 通向无限」），点卡片即选中；已选的会标「✓ 当前主题色」，顶部可一键取消 |
| `✕ 清除风格` | 恢复为不套画风 |

**生成时发生什么**：选了风格，点 `🎨 生成图片` 时会自动把一段「风格锚点」拼到提示词**最前面**——`风格名称：…。主题色：…。参考作者/风格名称：…。核心风格特征：…`（只有正面特征，已剔除「避免/不要」类负面描述），先定画风、再谈画面内容。

> 💡 **编号两套都认**：画廊里显示的新编号（如 `#FA-001`）和公众号文章里常见的传统编号（001–330）是同一批画风的两种编号，搜索框里输哪个都能找到。
> ⚠️ 风格锚点拼在提示词最前面；如果同时开了「自动优化提示词」，AI 润色可能改写这段锚点，追求画风稳定时可临时关掉优化。

### 7.3 人物一致性怎么用

1. 先在「素材中枢 → 👤 角色」把角色的外貌写清楚（或从设定导入）
2. 回到图片生成，在「人物一致性设定」里 `＋ 添加角色` 并指定
3. 之后同一角色的多张图就会保持长相一致——做角色立绘、短剧关键帧必用

## 十二、常见问题

**启动 / 安装**
- **双击 exe 没反应**：检查是否被杀毒软件拦截；或先运行 `安装WebView2.bat` 再试。
- **打开的是浏览器而不是原生窗口**：本机缺 WebView2，运行 `安装WebView2.bat`。
- **创作中枢提示「未随包提供引擎」**：说明 `inkos\` 文件夹没跟 exe 放在一起。把整个 `inkos\` 放到 exe 同级目录即可。
- **创作中枢一直转圈 / 引擎起不来**：点中枢页的「启动引擎」重试；仍失败时页面会把引擎日志摊开显示。常见原因是**端口 4567 被占用**（比如上次的进程没退干净），点「停止」再「启动引擎」。
- **点了生成没反应**：先看左下角「当前作品」是否已选中；再检查对应模型域是否配置了模型。

**模型相关**
- **下拉里没有我要的模型**：说明这个模型还没配置。先到「模型配置」对应入口把厂商和模型名填好并保存（Key 在「🏢 厂商与凭据」填一次，模型名在对应域的入口里挑）。
- **提示「请先到模型配置…」**：这是正常的引导——软件**只让你挑已配置的模型**，不会塞一堆用不了的模型名让你选。
- **云端模型返回 503 `model_not_found`**：该模型在你的账号下没分配上游渠道，换一个模型名（或填 `auto`）即可。
- **点 `↻ 拉取模型` 后名字后面有 ✕**：那个名字厂商列表里有、但**实测调不通**（已下线或没开渠道），点它会被拦下。换带 **✓** 的即可。
- **测试报「账号的余额/额度不足」**：这是**厂商账号没钱**，**不是 Key 的问题**，重填 Key 没有任何用 —— 去该厂商控制台充值或领免费额度。提示里会写明当前余额和本次需要多少。
- **点 `↻ 拉取模型` 却提示「可用性无法验证」**：同样是账号级问题（余额/Key/限流），此时软件**故意不把任何模型标成不可用** —— 因为整份清单一起失败是账号的事，不是模型的事。
- **v4.2.3 之前**：403 余额不足会被错报成「API Key 无效」，让人白折腾 Key；现在已按厂商报文精确区分（余额不足 / 模型不在清单 / 无可用渠道 / 已下线 / Key 真的错）。
- **v4.2.4 起**：所有失败都会弹出原因；报错提示默认停留 6 秒（模型相关的停 11~13 秒），点一下可立即关闭。
- **提示某模型「未通过检测」**：该模型在体检台账里被判不合格（下拉里仍保留并标注，不会被偷偷删掉）。换个模型，或到「本机与本地模型 / 各模型分节」页重新检测。
- **想用多个模型**：用 `📋复制框` 克隆出多个自定义端点，每个填一个模型名，**不要在一个框里塞多行**。
- **API Key 安全吗**：Key 仅保存在本机 `AppData\Roaming\左右小说制作器\` 并**加密**，不上传任何服务器。

**界面与提示**
- **点按钮完全没反应**：升级到 **v4.2.4 及以后** —— 任何失败的操作都会在右下角弹出红色原因提示。旧版本里「保存设置 / 保存路由 / 保存加速参数 / 重新检测硬件 / 清除配置 / 导出 / 删除作品」等按钮失败时可能毫无动静。
- **报错提示一闪而过看不清**：旧版本提示固定 2.6 秒。v4.2.4 起**报错默认停 6 秒**，模型相关长提示停 11~13 秒，并且**点一下提示就能立刻关掉**。
- **右下角提示太多**：最多同时 5 条，超出会自动移除最旧的；同一原因 3 秒内只提示一次，不会刷屏。
- **「重新检测硬件」一直转圈**：v4.2.4 起失败会把「硬件检测失败：<原因>」直接写在那一块，不会卡在加载动画上。
- **书架页空白 / 点了书没反应**：v4.2.4 起会明说「书架读取失败：<原因>」，并提示作品仍在本地、不会丢。
- **`Temp` 里还剩几个 `_MEI` 清不掉**：v4.2.8 起按目录**内容**认归属（不再只认「名字是纯数字」的老格式），旧版漏掉的那批现在也能回收。若还剩零星几个，多半属于**本机其它程序**的残留 —— 本软件按设计不会去碰它们。
- **退出后 Temp 里仍偶尔留 1 个 `_MEI`**：WebView2 子进程还握着文件锁，属已知情况，**不影响使用**，下次启动会自动回收。
- **运行日志是空的、不知道软件有没有真的启动**：v4.2.8 起每次启动都会在 `data\logs\左右工坊.log` 写一行 `启动 vX.Y.Z | 端口 … | 数据目录 …`。要排查问题，把这个日志和 `launcher_debug.log` 一起发给开发者即可。
- **打开软件时弹「检测到以下系统组件缺失」**：软件在自动检查 WebView2 运行库（决定用软件窗口还是退回浏览器）和
  ffmpeg 音视频引擎（短剧合成、有声书拼接要用）。点「是」就自动下载安装，每一步都有提示；
  点「否」也能照常用，只是对应功能不可用。
  > v5.8.22 起：点过「否」之后软件会**记住**，以后启动不再重复弹窗；
  > 想装的时候到「模型配置 → 🛠 高级设置 → 数据与备份 → 一键自检」，
  > 缺的那项右边有「安装」按钮，点一下就行。
- **「Ollama 缺失」的老提示**：Ollama 是**可选**的本地模型引擎，只用云端模型完全不需要它。
  v5.8.22 起这个提示默认不再打扰；要装到「模型配置 → 💻 本机与本地模型」点「一键安装 Ollama」，
  或双击发布包里的 `安装Ollama.bat`。
- **短剧/有声书报「未找到 ffmpeg」**：到「高级设置 → 数据与备份 → 一键自检」看「系统组件」分组，
  ffmpeg 那项右边点「安装」自动补上（v5.8.21 及之前自动装的位置不对，可能出现「显示装好了却仍报错」）。
- **C 盘越来越小 / 在 `Temp` 里看到很多 `_MEI` 开头的文件夹**：这是 v4.2.7 之前的解压残留（软件被强杀/关机时没清干净，一次约 200MB）。升到 **v4.2.7 及以后**：启动时会自动回收历史残留，并且退出时会自己清干净，不会再有新的堆积。若你想立刻回收旧的那一堆，装新版后启动一次即可（会自动清理，只清本软件的、超过 30 分钟的目录）。
- **`⟳ 生成大纲要点` 提示「未能从章节蓝图中解析出章节」**：v4.2.7 之前只认「行首就是 第N章」的写法。升到 v4.2.7 及以后即可正常解析 `## 第1章｜标题`、`第 1 章｜标题` 等常见写法。
- **Token 账本里大量记录显示 0**：v4.2.7 之前流式调用一律记 0。升到 v4.2.7 及以后，流式调用的用量会正常记账；厂商不回报用量的会按字数估算并标 `≈`。
- **真相文件编辑区被挤成一条窄竖条、正文像被框挡住**：这是 **v4.2.5 之前**的布局缺陷（生成要求框与编辑器被左右并排）。升级到 **v4.2.5 及以后**即恢复为上下排布，编辑器占满宽度。
- **生成要求框太长、把正文顶没了**：v4.2.5 起生成要求框最多占右栏高度的 45%，超出部分在框内自己滚动，正文区始终保留足够空间。

**写作相关**
- **「确认动作失败」**：多半是模型不过工具调用 schema。到「模型配置 · 📖 小说模型」点 `🧰 检测工具调用` 换一个合格的模型。
- **总体规划 / 阶段规划只写到一半就停了**：长书单次生成可能被模型输出长度截断——把「每段章数」调小，让软件自动分段生成即可绕开。
- **生成出的「角色矩阵」里混着大量分析/方法论废话，甚至复读打转**：这是模型把内心

- **歌曲/音频生成很慢**：属正常，是「提交 → 轮询」模式，几十秒到几分钟。

## 十三、开发者模式（可选，需源码仓库）

> 本节内容需要软件开发仓库（含 `server/`、`web/`、`build_exe.py`、`启动.bat`），**发布包里没有这些文件**，普通用户可跳过。

需要本机有 **Python 3.10+**：

- 未安装：到 https://www.python.org/downloads/ 下载，安装时务必勾选 **"Add python.exe to PATH"**
- 启动：`启动.bat`（自动找 Python → 起服务 → 开浏览器）
- 或手动：`python server/app.py --port 8901`

### 重打包 exe

```bash
pip install pywebview pyinstaller
python build_exe.py        # 自动读取 server/config.py 里的版本号，产物名带版本号
```

产物为单文件 `左右工坊_vX.Y.Z.exe`（无控制台、含 WebView2 原生窗口 + 浏览器回退）。
版本号同步用 `python bump_version.py --set X.Y.Z`（一次改齐 5 处）。
