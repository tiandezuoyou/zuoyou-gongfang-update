## 一、最省事：直接当桌面软件用（推荐）

1. 双击主目录下的 **`左右工坊_v2.2.31.exe`**（文件名带版本号，主文件夹始终只保留最新版）
2. 自动弹出**原生软件窗口**（像普通 Windows 软件一样，没有黑框、不依赖浏览器）
3. 关掉窗口即退出
4. 首次打开若弹出的是浏览器窗口而非原生窗口，多半是本机缺 WebView2 运行时——双击 **`安装WebView2.bat`** 装一下，以后就都是原生窗口了（不装也能用，只是走浏览器）

> 该 exe 是**单文件、完全自包含**：后端和前端界面都打在里面，可以单独复制到任意文件夹 / U 盘使用，无需安装 Python。

### 数据存在哪？

单文件 exe 是便携的，所以你的小说工程、配置等可写数据会落在当前用户目录：

```
C:\Users\你的用户名\AppData\Roaming\左右小说制作器\
├── 作品\      ← 你创作的小说
├── data\      ← 配置(config.json)与缓存
```

这样无论 exe 放在哪都不会丢数据。API Key 经过本地加密后存于该目录，**不会上传到任何服务器**。

## 三、设定工坊：四步递进搭骨架（小说创作核心）

进入「设定工坊」后，顶部有 **①②③④ 四步进度条**，按这个顺序搭出全书骨架。每一步的产物都会自动成为下一步的上下文，**所有内容都能在右侧编辑器里随意修改——生成的内容只是"大概方向"，你随时可以增删调整**。

### 第一步 · 设定：人物 · 人物关系 · 世界观

- 点 **① 生成世界设定**，基于书名/题材/简介产出世界设定（力量体系、时代地域、势力关系等），落盘 `设定/世界设定.md`。
- 在左侧「真相文件」列表里**逐个点开生成** 7 份事实来源（人物矩阵、人物关系、当前状态、资源账本、伏笔钩子、作者意图、近期焦点）。写手与审计员都以它们为准，**避免前后人物/地名冲突**。
- 每点一个文件，右上会出现该文件的「生成要求」与「额外要求」，填完点 **🎯 生成这个文件** 即可；生成后点「保存」才落盘。

### 第二步 · 总体规划（仅定方向，不写细纲）

- 在「📖 全书章节数」里填总章数（**最多 5000 章**，千章长篇也支持），点 **② 生成总体规划**。
- 软件把全书划分为 **3~5 个阶段**，标注每阶段的章号区间（如 第1~8章 / 第9~20章 / 第21~40章）与阶段主题、起承转合节奏。落盘 `大纲/总体规划.md`。
- ⚡ **章节很多时自动分段生成**：若总章数超过「每段章数」，总体规划会像阶段规划一样**分多段生成**，绕开单次输出被模型截断的问题。

### 第三步 · 阶段规划（分段细纲）

- 在「每段章数」里填**每一段多少章**（比如填 50 = 每 50 章为一段），点 **③ 分段生成阶段规划**。
- 软件逐段写出**每一章大致发生什么**，落盘 `大纲/章节蓝图.md`。长书分多段生成，避免一次性输出过长被截断。
- 生成过程中可看进度与「取消」；已完成的段会保留，未完成的段会回滚。

### 第四步 · 逐章生成（落地正文）

- 点 **④ 去章节流水线写正文 →**，跳到「章节流水线」按章号逐章生成。
- 前三步的设定 / 总体规划 / 阶段规划会自动作为写手上下文，**保证正文不跑偏**。
- 章节流水线支持单章 / 连写 / 半自动（关键点确认），并可强制去 AI 味。

> 💡 **省事入口**：底部「🚀 一键走完四步并生成全文」会按 ①设定 → ②真相 → ③总体规划 → ④阶段规划 → ⑤逐章 一气呵成，长书同样自动分段。

### 导入已有小说（文件夹）

如果你手里已经有一部写好的小说（txt / md），想用本软件继续写、或自动补全设定 / 大纲 / 人物关系，点书架页的 **📂 导入已有小说**：

1. **选文件夹**：粘贴完整路径（如 `D:\小说\我的书`），或用「📁 选文件夹」按钮辅助。
2. **多本自动停止**：软件会扫描文件夹里所有章节。若发现**多本小说**（文件夹里有多个子文件夹各是一本，或一个文件里出现多个不同的「第 1 章」开头），会**直接停止并弹出提示**，列出检测到的书名，请你把每本放到各自文件夹再分别导入。
3. **单本继续**：若只有一本（一个文件、或多个文件拼成一本都行），软件会：
   - 自动建书，把章节按序落盘到 `正文/`；
   - **自动锁定已导入的原文**（保证续写时原文不被改动，一致性）；
   - **第一步**自动从正文**提取**人物 / 人物关系 / 世界观（只提取能确认的内容，没提到的留「待补充」，不凭空编造），你可在右侧编辑器补充、确认；
   - 之后 **第二步总体规划 / 第三步阶段规划 / 第四步逐章生成** 与新建作品完全一致，每一步都能改、确认后再继续。
4. **从已有处续写**：第四步点「去章节流水线」即从**最后一章之后**接着生成；由于原文已锁定，生成的新章与原文人物、伏笔、节奏保持一致。

> 适合「半本书想交给 AI 续写」「已有草稿想自动整理出人物关系表 / 大纲」等场景。

### 每章字数硬性约束

软件已内置固定规则：**每一章正文（中文纯字数，不计标题/标点）必须落在 1500~2500 字之间**。无论你在流水线里填的单章字数多少，最终都会被钳到这个区间；写手 prompt 也明确告知模型该范围，系统还会在成稿后自动补足或截断到区间内。

## 四、大模型使用介绍（重点）

软件把"用哪个模型"和"生成什么"解耦：先在大模型页把厂商对接好，再到各工坊选模型生成。

### 4.1 大模型页在哪里

左侧导航「大模型」分组下有四类对接入口：

- **云端大模型**（对话 / 写作主力）：DeepSeek、硅基流动、通义千问、Kimi、智谱、火山方舟、MiniMax、OpenRouter、OpenAI、Claude、Gemini、**幻城 hcnsec 公益大模型** 等
- **视频模型**：视频生成厂商
- **图片模型**：图像生成厂商
- **音频模型**：语音合成厂商（hcnsec 语音等）

### 4.1.1 每个工坊对应哪个模型域（对照表）

为避免不知道"该对接哪个模型"，下表把**工坊 → 需要对接的模型域 → 可对接厂商**列清楚。模型中心每个域顶部也会显示这一行说明。


| 工坊 / 功能                              | 需要对接的模型域                                                                  | 可对接的厂商（预设，均可多家并存）                                                                                                                          |
| ---------------------------------------- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **小说工坊**（设定 / 大纲 / 章节生成）   | 云端大模型                                                                        | hcnsec、DeepSeek、硅基流动、通义、Kimi、智谱、火山方舟、MiniMax、OpenAI、Claude、Gemini 等（任意 OpenAI 兼容即可）                                          |
| **视频工坊**（文生 / 图生视频）          | 视频模型                                                                          | MiniMax 海络、可灵、通义万相 Wan、智谱清影、即梦 Seedance、硅基流动、Vidu、本地 ComfyUI 等                                                                  |
| **图片工坊**（生图 / 垫图）              | 图片模型                                                                          | Pollinations（免费）、硅基流动 FLUX、智谱 CogView、通义万相、即梦 Seedream、本地 ComfyUI、hcnsec 等                                                         |
| **短剧模式**（剧本分析 + 关键帧 + 配音） | ① 云端大模型（分析剧本）<br>② 图片模型（人物关键帧）<br>③ 音频模型（角色配音） | 分析：任意云端模型；关键帧：图片模型任意一家；配音：音频模型任意一家                                                                                        |

| **歌曲生成**（主题 → 歌词 → 成曲）     | 歌曲引擎（在「音频模型中心」底部区块）                                            | ACE-Step（本地开源）、Suno 兼容网关（自定义端点）                                                                                                           |

> 💡 每个域都**支持多家并存**：同一域里可以保存多个厂商，生成时再下拉选具体哪家。例如音频模型中心里可以同时对接 hcnsec + 硅基流动 + 通义 CosyVoice，短剧配音时按角色分别选不同厂商/音色。

### 4.2 一张厂商卡片怎么填

每个厂商是一张卡片，从上到下：

1. **厂商名称**（预设卡片显示官方名；自定义端点可改名）
2. **厂商说明** + 免费 / 推荐 / 付费 标签 + 注册链接
3. **API Key**：厂商给的密钥（仅存本地、加密）
4. **Base URL**：接口地址（预设已填好，一般不用改）
5. **模型名称**：**你要用哪个具体模型**（最关键的字段，见 4.4）
6. **保存 / 测试 / 快速测链 / 清除** 按钮

> 💡 **免费**标签 = 该厂商有免费额度；**💰付费**标签 = 调用会产生费用（不会被禁用，仅作提示）；**🌟推荐** = 编辑精选、免费额度多或性能好。

### 4.3 推荐首选：幻城 hcnsec 公益大模型

这是软件**默认排在第一位**的厂商，理由：公益免费、国内直连稳定、聚合了 30+ 大模型供应商。

- **平台地址**：`https://api.hcnsec.cn/`
- **控制台 / 注册**：`https://api.hcnsec.cn/console`（用邀请码 `aff=NXjz` 注册，注册即送 29200 余额，每日签到再领免费额度）
- **接口**：OpenAI 兼容，`Base URL = https://api.hcnsec.cn/v1`
- **已内置 47 个真实模型名**（来自官方教程文档 V2.0），覆盖：
  - 通义千问 Qwen：`Qwen3-235B` / `Qwen3-Coder` / `Qwen3.5-397B-A17B` / `Qwen3.5-plus` / `Qwen3.6-35B-A3B` / `qwen3.7-plus` 等
  - 智谱 GLM：`glm-4.7-flash` / `glm-4.7` / `glm-5` / `glm-5.1` / `glm-5.2`
  - 深度求索 DeepSeek：`DeepSeek-V4-Flash` / `DeepSeek-V4-Pro` / `deepseek-v3.2` / `deepseek-v4-flash` / `deepseek-v4-pro`

> ⚠️ **真实可用性以平台 `/v1/models` 接口返回为准**。个别模型在你的账号下可能没分配到上游渠道（会返回 HTTP 503 `model_not_found`），此时换一个模型名即可（如 `Qwen3-235B` 不可用时改用 `Qwen3.5-plus` / `deepseek-v4-flash` / `auto`）。

### 4.4 模型名称怎么填（重要）

- **模型名称**框填的是**具体模型 ID**，不是厂商名。
- 可填**多个**，用英文逗号 `,` 隔开（如 `flux,flux-pro`）。
- 💡 **想省事填 `auto`**：`auto` 是平台智能路由，会自动选当前最优可用模型——**但价格较贵**。
- 💡 **想省钱**：自行填具体模型名（如 `deepseek-v4-flash`），费用更低。
- ⚠️ **同一框内不要填多行 / 不要一行塞一堆模型名**，某些接口会报错。需要多个模型时，请**分开成多个框**（见 4.5 的"复制框"）。

### 4.5 「📋复制框」：快速克隆一个厂商配置

点任意厂商卡片上的 **📋复制框** 按钮，会**自动在下方"自定义"栏生成一个新框**，并自动带上原框的：

- API Key
- Base URL
- 模型名称（**显示原框的模型名，可直接修改，不会空白**）
- 名称（自动叫"原厂商名 副本"，**一定有名字**，可在最上方改）

用途：

- 同一个 Key 想用不同模型？克隆后改模型名即可，不用重填 Key。
- 避免"一个框里填多行模型名报错"——每个模型各占一个框。

> 克隆出的新框是"自定义端点"，**改完最上方的名称后要点「保存」才会落盘**（和软件原有规则一致，关窗口不保存会丢）。

### 4.6 测试连通性

填好 Key 和模型名后，点卡片上的 **测试** 或 **快速测链**：

- 测试：用你填的模型实际发一次请求，返回延迟与样例回复
- 快速测链：仅验证 Base URL 与 Key 是否可达
- 返回 `连通正常 · xx ms` 即对接成功

### 4.7 本地大模型（Ollama）

1. 双击 **`安装Ollama.bat`** 安装 Ollama 运行环境（也可直接运行 `ollama/OllamaSetup.exe`）
   > exe 内置**不含** Ollama 安装包（体积过大），请在本目录保留 `ollama/OllamaSetup.exe`，或自行从 https://ollama.com 下载。
   >
2. 安装后，在软件「大模型」页一键拉取模型
3. 软件会根据你的电脑配置（显卡/内存）推荐可流畅运行的本地模型与量化版本
4. 下载加速：配置里可选 modelscope / hf-mirror 镜像源

## 五·补 A、短剧模式（视频工坊内 🎭 短剧模式）

把一段**文字剧本**变成一部**人物一致、音色统一、带字幕**的短剧视频。全程 AI 自动拆解，每一步都能手动改。

**前置对接**（一次性）：

- **图片模型**：去「图片模型」页对接一个图像厂商（Pollinations / DashScope / Seedream 等）——用于生成"人物一致"的关键帧。
- **音频模型**：去「音频模型」页对接一个 TTS 厂商（hcnsec 语音等）——用于按角色音色配音。
- 视频合成用的 **ffmpeg 已内置在 exe 里**，无需额外安装。

**使用步骤**：

1. 进「视频工坊 → 🎭 短剧模式」，在剧本框粘贴你的剧本（谁在哪儿、说了什么）。
   - 可选：下方「分析模型」下拉可指定用哪个云端/本地大模型拆解剧本（留空则用默认已启用模型）。
2. 点 **🔍 分析剧本**，AI 会把它拆成：
   - **标题 / 统一风格**（卡通 / 动漫 / 写实 / 真人电影感 等）
   - **人物表**：每个角色的外观描述 + 音色（female / male / default）——这是"人物一致、音色统一"的关键
   - **场景 / 对白**：每段场景的时空设定 + 逐句台词（说话人须与人物表对应，旁白用「旁白」）
3. **逐处修改**：标题、风格、人物描述/音色、每一句台词都能在右侧编辑器里改。改完点 **💾 应用修改**。
4. 在底部选 **图片厂商 / 音频厂商**（以及各自模型、分辨率），点 **🎬 生成短剧视频**。
5. 进度条走完后，直接在界面里**预览 / 下载**生成的 MP4。

> 💡 成片结构：自动在开头加一段 **3 秒片头标题卡**（显示剧名 + 风格副标题），场景之间还会插入短 **转场卡** 制造停顿过渡感——让成片更像"完整的短剧"而非生硬拼接。片头/转场颜色会随你选的风格（卡通/动漫/写实/真人电影感/水彩/像素风）自动变化。
> 💡 想保证"同一角色长一个样"：人物描述（desc）写得越具体稳定，跨场景生成的关键帧越一致；音色按人物表锁定，不会串角色。
> ⚠️ 某个场景生图失败会用纯色占位图兜底、某句配音失败会用静音兜底，保证视频不中断——但最好提前测好对应厂商连通性。

## 五·补 B、歌曲生成（音频工坊内 🎵 歌曲生成）

输入一个**主题**，AI 写出可修改的歌词，再按你选的**风格**生成一首完整歌曲。

**前置对接**（一次性）：

- 去「歌曲生成」模型页（在「大模型」分组下的歌曲生成卡片）对接一个歌曲引擎：
  - **ACE-Step**（本地扩散基座，默认指向 `http://127.0.0.1:8000`，需本机/局域网跑起 ACE-Step 服务）
  - **Suno 兼容网关**（填网关 Base URL + Key，对接兼容 Suno API 的第三方服务）
- 风格可选：流行 / 古风 / 国风 / 摇滚 / 说唱 / 民谣 / 电子 / 抒情 / R&B / 二次元 / 爵士 / 轻音乐。

**使用步骤**：

1. 进「音频工坊 → 🎵 歌曲生成」，填**主题**（如"夏日海边毕业季的告别"）。
   - 可选：下方「作词模型」下拉可指定用哪个大模型写歌词（留空则用默认已启用模型）。
2. 选**风格**，点 **📝 生成歌词**——AI 产出带 `[主歌]/[副歌]/[桥段]` 标记的可编辑歌词。
3. **改歌词**：在文本框里直接润色、增删段落。
4. 选**歌曲引擎厂商**（及模型），点 **🎵 生成歌曲**。
5. 轮询进度走完后，在界面里**试听 / 下载**生成的歌曲音频；结果卡片会**一并展示这首歌的歌词文本**，方便你对照 / 复制保存。

> 💡 歌词质量直接决定成曲质量，先用「生成歌词」跑一版再精修，比直接硬写省事。
> ⚠️ 歌曲引擎是"提交→轮询"模式，生成可能要几十秒到几分钟，可随时「取消」。

## 常见问题

- **双击 exe 没反应**：检查是否被杀毒软件拦截；或在「安装WebView2.bat」后再试。
- **打开的是浏览器而不是原生窗口**：本机缺 WebView2，运行 `安装WebView2.bat`。
- **本地模型跑不动**：在「系统/配置」页按电脑配置选更小的量化版本。
- **云端模型返回 503 model_not_found**：该模型在你的账号下没分配上游渠道，换一个模型名（或填 `auto`）即可。
- **想用多个模型**：用「📋复制框」克隆出多个自定义端点，每个填一个模型名，不要在一个框里塞多行。
- **总体规划 / 阶段规划只写到一半就停了**：长书单次生成可能被模型输出长度截断——把「每段章数」调小，让软件自动分段生成即可绕开。
- **每章字数不对**：软件已强制每章 1500~2500 字，流水线里填的单章字数超出范围会被自动收敛，属预期行为。
- **API Key 安全吗**：仅保存在本机 `AppData\Roaming\左右小说制作器\` 并加密，不上传任何服务器。
- **短剧模式生成失败/不出视频**：先确认已在「图片模型」「音频模型」页对接好厂商（生成关键帧和配音都依赖它们）；视频合成所需的 ffmpeg 已内置，无需另行安装。某张图/某句配音失败会自动用占位图/静音兜底，保证成片不中断。
- **歌曲生成一直"生成中"**：歌曲引擎是"提交→轮询"模式，首次生成可能要几十秒到几分钟；ACE-Step 需本机/局域网先跑起服务（`http://127.0.0.1:8000`），Suno 兼容网关需填对 Base URL 与 Key。久等不出可在界面点「取消」。
- **短剧视频人物不像同一个人**：人物"外观描述(desc)"写得越具体稳定，跨场景生成的关键帧越一致；音色按人物表锁定，不会串角色。
